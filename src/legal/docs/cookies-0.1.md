# Cookie and Tracking Notice

Amigo uses only what it needs to work. We don't use advertising cookies, cross-site tracking or analytics services.

## Cookies

| Name | Purpose | Type |
| --- | --- | --- |
| Sign-in session (set by Neon Auth, our authentication provider) | Keeps you signed in | Strictly necessary, first-party |

## Storage in your browser

| What | Purpose |
| --- | --- |
| Theme preference | Remembers light/dark mode |
| Drafts | Keeps an unsent post if you leave the composer |
| Encryption keys (IndexedDB, encrypted at rest) | Lets this device read and send your encrypted messages |
| Device id for messaging | Identifies this browser as one of your messaging devices |

Strictly necessary storage doesn't need consent. If we ever add optional analytics or similar tracking, we'll ask for your consent separately first, and you'll be able to change your choice at any time.

Clearing your browser's storage signs you out and removes this device's encryption keys — set up message backup in **Settings → Security** so you can restore your history.
