# Thank-you / trailer teaser banner

Thanks everyone who reserved a username and teases the upcoming official trailer. It uses the same brand system as the launch and reservations banners:
- **Colours:** coral `#ff5a3c` and violet on near-black.
- **Type:** Bricolage condensed headlines and Geist body text, both the site's own fonts.
- **Logo and motif:** the coral "a" logo tile and the glowing orbital world.
